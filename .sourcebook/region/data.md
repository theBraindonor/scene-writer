# Data

Owns the local SQLite database — schema and ORM models (via SQLAlchemy) for scenes and the data generated by each pipeline phase. The database file lives under the top-level `data/` folder; the folder itself is tracked in git via a placeholder, but the database file(s) are gitignored. `scene.core` is the only package that talks to `scene.data` directly — `scene.cli` and `scene.agent` go through `scene.core`'s service layer instead.
