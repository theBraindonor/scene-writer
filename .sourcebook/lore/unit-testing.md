# Unit Testing

New and modified code must be covered by unit tests. All unit tests must be passing before any work can be marked as completed.

Tests are written with `pytest` and live under the top-level `test/` folder, outside `src/`. Each test file's path mirrors the path of the module it covers (e.g. `src/scene/data/foo.py` → `test/scene/data/test_foo.py`).

Coverage is measured via `pytest`'s HTML coverage report, which is generated by default on every test run.
